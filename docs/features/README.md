# Features Documentation

This directory contains detailed documentation for each major feature of the IDTA Submodel Template Editor.

## Feature Guides

| Feature | Description |
|---------|-------------|
| [Semantic Lookup](semantic-lookup.md) | Search ECLASS/IEC CDD dictionaries and attach semantic identifiers |
| [Smart Mapper](smart-mapper.md) | CSV/XLSX bulk import with column profiling and recipe management |
| [PCF Calculator](pcf-calculator.md) | Carbon footprint calculation and IDTA 02023 validation |
| [Passport Mode](passport-mode.md) | Digital Product Passport visualization |
| [Magic Import](magic-import.md) | PDF-to-AAS extraction with LLM and OCR support |
| [Dataspace Publishing](dataspace-publishing.md) | Manufacturing-X / Catena-X connectivity |
